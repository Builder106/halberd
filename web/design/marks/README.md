# Marks

`halberd-head.svg` was drawn in Glaxnimate. It is a spike, a crescent
blade, a back spike and a shaft, on a 48 by 72 grid with the shaft
centred at x = 24.

It is used in two places:

- `src/components/Mark.tsx` inlines the paths with `currentColor`. On the
  session page the shaft continues as Halberd's lifeline.
- `src/app/icon.svg` is the favicon, cropped to the head.

Redraw it here first, then copy the path data into both files.
